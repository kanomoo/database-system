💡 คู่มือสำหรับมือใหม่: วิธีสร้างไฟล์และรัน SQL บนเครื่องจริง

หากอาจารย์ให้ไปเตรียมตัวทำแล็บในห้องเรียน แล้วคุณยังไม่เคยสร้างไฟล์หรือรันบนคอมพิวเตอร์ของคุณเอง ให้ปฏิบัติตาม 3 ขั้นตอนนี้:

1. วิธีสร้างไฟล์ .sql ใน VS Code

1. เปิดโปรแกรม VS Code แล้วกดไปที่ File → Open Folder เลือกโฟลเดอร์สำหรับเก็บงานวิชา Database

2. กดไอคอน New File แล้วพิมพ์ชื่อไฟล์ลงท้ายด้วย .sql เช่น lab1.sql หรือ query.sql

3. คุณสามารถพิมพ์คำสั่ง SQL แล้วบันทึกไฟล์ได้เหมือนไฟล์ข้อความทั่วไป

2. วิธีติดตั้ง Extension เพื่อรัน SQL ใน VS Code

1. กดคีย์ลัด Ctrl + Shift + X ใน VS Code เพื่อเปิดหน้าค้นหา Extensions

2. ค้นหาคำว่า "SQLite Viewer" โดย Florian Klampfer (ใช้ดูไฟล์ .db แบบมีตารางสวยงาม)

3. หรือค้นหา "SQLTools" และติดตั้งไดรเวอร์ฐานข้อมูลที่อาจารย์ใช้ (เช่น MySQL หรือ SQLite)

3. ทางเลือกที่ง่ายที่สุด: ใช้ DB Browser for SQLite

หากอาจารย์ใช้ SQLite ให้ดาวน์โหลดโปรแกรมฟรีชื่อ DB Browser for SQLite (sqlitebrowser.org):

• เปิดโปรแกรมแล้วกดปุ่ม New Database ตั้งชื่อไฟล์เช่น mydb.db

• สลับไปที่แท็บ Execute SQL

• ก๊อปปี้โค้ด SQL จากเว็บนี้ไปวาง แล้วกดปุ่ม Play (F5) เพื่อรันดูผลลัพธ์ได้ทันที!

4. ทำไมฝึกบนเว็บนี้ถึงดีที่สุดก่อนเข้าห้องเรียน?

เว็บแอปนี้ฝัง SQLite WASM Engine เอาไว้ในตัวเบราว์เซอร์แล้ว ไม่ต้องติดตั้งโปรแกรมอะไรเพิ่ม คุณสามารถลองพิมพ์คำสั่ง ลองแก้ ล้างตาราง และกดรันเพื่อดูผลลัพธ์ได้ 100% เสมือนอยู่ในห้องแล็บจริง!

⌨️ คีย์ลัดตัวแก้ไขโค้ด (VS Code Shortcuts)

ห้องทดลองนี้รองรับคีย์ลัดยอดนิยมเหมือนโปรแกรม Visual Studio Code ช่วยให้เขียนและแก้ไข SQL ได้อย่างรวดเร็ว:

Ctrl + / คอมเมนต์ / ยกเลิกคอมเมนต์บรรทัด (Toggle Line Comment --)
Ctrl + Enter รันคำสั่ง SQL ทันที (Run Query)
Tab / Shift + Tab เพิ่ม / ลด ย่อหน้า 2 เคาะ (Indent / Outdent ทั้งบรรทัด)
Alt + ↑ / ↓ สลับย้ายบรรทัดขึ้น / ลง (Move Line Up / Down)
Shift + Alt + ↓ / ↑ ก๊อปปี้ทำซ้ำบรรทัดลงล่าง / ขึ้นบน (Duplicate Line Down / Up)
Ctrl + Shift + K ลบบรรทัดปัจจุบันทิ้งทันที (Delete Line)
Ctrl + D เลือกคำที่เคอร์เซอร์อยู่ / หาคำถัดไป (Select Word / Next Match)
Ctrl + Space เปิดหน้าต่างแนะนำคำอัตโนมัติ (IntelliSense Autocomplete)
Shift + Alt + A คอมเมนต์แบบบล็อก (Block Comment /* ... */)
พิมพ์ ' หรือ ( ปิดวงเล็บ/คำพูดให้อัตโนมัติ (หากไฮไลต์ข้อความไว้จะครอบคำให้)
Enter ขึ้นบรรทัดใหม่พร้อมรักษาระยะย่อหน้าอัตโนมัติ (Smart Indent)
