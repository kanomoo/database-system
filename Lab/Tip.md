# 💡 Tips การรัน SQL และดูผลลัพธ์แบบ Real-Time

### 1. การรันคำสั่ง (Run Execution)
- **`Ctrl + Shift + B`** : รันไฟล์ SQL ปัจจุบันทั้งไฟล์เข้าสู่ `lab.db` (มีข้อความรายงานสถานะ + จำนวนแถวที่เปลี่ยนแปลง `changes`)
- **`Ctrl + Enter`** : รันคำสั่ง SQL บรรทัดที่เคอร์เซอร์อยู่ (ผ่าน Database Client) หรือคลิก **`▶ Run SQL`** เหนือบอร์ดโค้ด

### 2. ดูข้อมูลแบบ Real-Time (วิธีที่ 1 & 2 ที่ปรับตั้งค่าให้แล้ว)
- **Auto-Refresh Real-Time 1s:** ตั้งค่าให้ Database Client เปิดโหมดรีเฟรชทุก 1 วินาทีอัตโนมัติแล้ว เมื่อมีการ INSERT, UPDATE, DELETE หรือแก้ไขข้อมูล ตารางฝั่งขวาจะอัปเดตให้อัตโนมัติทันที
- **Auto-Split View:** ตั้งค่าให้เมื่อกดรันคิวรีผ่าน Database Client หน้าต่างจะแบ่งซ้าย-ขวา (โค้ดอยู่ซ้าย ผลลัพธ์/ตารางอยู่ขวา) ให้ทันที
