อาจารย์:
"ก็เป็นแฟ้มข้อมูลที่เป็นไฟล์นะคะ จำได้มั้ย ที่อาจารย์เคยบอก... จำได้มั้ยคะ อาจารย์เคยบอกเรื่องเกี่ยวกับว่า ในตัวแฟ้มข้อมูลของเรา จะประกอบไปด้วยไฟล์เนี่ยประมาณ 3 ประเภท จะมีไฟล์นะคะที่เราเรียกว่า เป็นไฟล์พื้นฐาน นะคะ แล้วก็ Master File นะคะ แล้วก็ Transaction File นะคะ... อันนั้นคือไฟล์ สำหรับการเก็บข้อมูลเนาะ...

ถัดมานะคะ ถัดมาตัวที่เป็น Transaction นะคะ ตัวนี้ เราจะหมายความว่าเป็นลักษณะของ นะคะ ตัวรายการที่เกิดขึ้นในแต่ละไฟล์ ในแต่ละไฟล์เนี่ยนะคะ จะมีตัว Transaction ที่เกิดขึ้นได้ นะคะ
Transaction คืออะไร Transaction ที่ไม่ใช่ไฟล์นะ เป็น... Transaction เป็นหมายถึงว่า เป็นคำสั่ง ที่เอาไว้ใช้สำหรับ นะคะ ทำรายการในแต่ละไฟล์นั่นเอง นะคะ เป็นรายการที่เกิดการเปลี่ยนแปลง นะคะ ไม่ว่าจะเป็นคำสั่งที่ใช้ในการ INSERT คือการเพิ่มข้อมูล หรือคำสั่งที่ใช้ในการ UPDATE คือทำการแก้ไขข้อมูล หรือคำสั่งที่ใช้ในการ ลบข้อมูล (DELETE) เราถือว่าเป็น Transaction ทั้งสิ้นนะคะ...
เพราะฉะนั้น ที่เป็นไฟล์ทั้งไฟล์พื้นฐาน ไฟล์ที่เป็น Master Data แล้วก็ไฟล์ที่เป็น Transaction นะคะ จำเป็นจะต้องมีการใช้คำสั่งที่เราเรียกว่า Transaction ในการจัดการตัวข้อมูลทั้งนั้นเลย นะคะ...

รวมไปถึง นะคะ รวมไปถึงคำสั่งที่เราเรียกว่าเป็นคำสั่ง Query ข้อมูลด้วย คำสั่งที่ใช้ในการสืบค้นข้อมูล เราก็ถือว่าเป็น Transaction อันหนึ่ง เพราะเราเขียนคำสั่งให้ใช้สำหรับทำการสืบค้นข้อมูล นี่คือ Transaction นะคะ...

อย่างที่อาจารย์บอก Transaction ที่เราเคยเรียนไปเกริ่นไปตั้งแต่ตอนสัปดาห์แรกๆ เนี่ย จำได้มั้ยคะ Transaction หนึ่ง อาจจะประกอบไปด้วยคำสั่งเดียว หรือหลายๆ คำสั่งก็ได้ เพื่อทำงานให้เราจนเสร็จสิ้นตามที่เราต้องการ นะคะ
ไม่ว่าจะเป็น นะคะ การที่เราทำการ นะคะ เปิดบัญชีใหม่ จะใช้กี่คำสั่งก็ไม่รู้แหละ นะคะ แต่คือหนึ่ง Transaction... หรือว่าในการที่เราทำการแก้ไขข้อมูลของนักศึกษา จะใช้กี่คำสั่งก็ไม่รู้ นะคะ ก็ถือว่าเป็นหนึ่ง Transaction... หรือว่าการจอง การจองตั๋วเครื่องบิน อาจจะใช้หลายคำสั่ง ก็ถือว่าเป็นหนึ่ง Transaction เคเนาะ...
อย่างคราวที่แล้วที่อาจารย์ได้เคยยกตัวอย่างไป นะคะ ในการจองตั๋วเครื่องบิน ทำไมคะ ก็อาจจะมีคำสั่งหลายๆ คำสั่งเลย ถูกมั้ยคะ...

คราวนี้ นะคะ อะ เดี๋ยวเรามาดูกันนะคะ... อาจารย์ลืมไปเลยค่ะ เดี๋ยวเนอะ สมุด คราวที่แล้วของใครนะอันเนี้ย ปากกาคืนไปมั้ยคะ เหมือนจะเอาไปใช้ นะคะ ของใคร อะยกมือค่ะ ของใครคะ... อะเดี๋ยวส่งไปนะคะ เล่มสีอะไร สีเขียว แล้วของใครคะสีเหลืองกับสีชมพู... ส่งไปให้เพื่อนด้วยลูก... สีนี้กับสีชมพูไม่รู้ของใครนะ ยังไม่มามั้งเนาะ ให้เค้ามารับไปด้วยนะ เผื่อจะเขียนอะไร นะคะ...

อะ เริ่มเลยนะ คราวนี้เรามาดู นะคะ เรามาดูเริ่มแรกเลย นะคะ ตัว Transaction นะคะ ที่อาจารย์บอกว่าเป็นคำสั่ง นะคะ ที่เอาไว้ใช้สำหรับทำการจัดการตัวข้อมูลให้กับเรา นะคะ ในอันแรกนี้ นะคะ ในอันแรกนี้ ตัว Transaction นะคะ เรามาดูตรงนี้ นะคะ เรามาดูที่ สี่เหลี่ยม 2 อันนี้น้อ ในอันแรก นะคะ สี่เหลี่ยมเนี้ย เราเรียกว่าเป็น Application Program กับอันนี้นะคะ เค้า ทำการจำลองให้เห็น ว่าเป็นลักษณะของตัว Database Table เค้าแค่จำลองนะคะ แต่ความจริงไม่ได้มีลักษณะแบบนี้ เค้าแค่จำลองให้เห็น
ตัว Application Program เนี่ย เค้าก็ทำการเขียนโค้ดเพื่อรองรับเหมือนกัน นะคะ ทั้ง 2 แผนก คือ บัญชี นะคะ ส่วนตรงนี้เป็น ให้เรามองเห็นว่าเป็น Table นะคะ มี Table Saving Account กับ Table Checking Account นะคะ มีอยู่ 2 Table คือ 2 บัญชี นะคะ...

คราวนี้ เรามาดูก่อนนะคะ ใน Transaction นี้ นะคะ สมมุติว่า เป็นลักษณะของ นะคะ การโอนเงิน นะคะ ต้องการโอนเงินจากบัญชี Saving Account ไปที่บัญชี Checking Account นะคะ เป็นการโอนเงินเนาะ นะคะ เรามาดูนะคะว่าเค้าทำอะไรบ้าง อันนี้คือ 1 Transaction ที่เกิดขึ้นคือการโอนเงินนะ เค้าทำอะไรบ้าง นะคะ...
เราต้องรู้ก่อน เวลาที่เค้าโอนเงินเนี่ย เวลาเค้าโอนเงิน เค้าทำยังไงคะ เค้าก็จะต้องมีการหักยอดจากบัญชีผู้โอนเนาะ อะ ก็คือตัดยอดออกเหมือนเป็นการถอนเงิน กับอีกอันนึงที่เค้าทำก็คือ บัญชีผู้รับ เค้าก็จะทำการฝากยอดเงินเข้าไปในบัญชีผู้รับ เราก็เรียกว่าเป็นการโอนเงิน..."

[สรุปสาระสำคัญและจุดเน้น (Key Takeaways)]
1. แฟ้มข้อมูล 3 ชนิด: Basic File, Master File, Transaction File
2. นิยาม Transaction: ไม่ใช่ไฟล์ข้อมูล แต่คือ "ชุดคำสั่ง" (INSERT, UPDATE, DELETE, QUERY) ที่กระทำต่อฐานข้อมูล
3. องค์ประกอบ: 1 Transaction อาจมีคำสั่งเดียวหรือหลายคำสั่งต่อเนื่องกันเป็นหน่วยงานเดียว
4. ตัวอย่างธุรกรรมการโอนเงิน:
   - ตารางที่เกี่ยวข้อง: Saving Account (ออมทรัพย์) และ Checking Account (กระแสรายวัน)
   - ขั้นตอน: หักยอดเงินผู้โอน -> ฝากยอดเงินเข้าผู้รับ (ต้องสำเร็จทั้งคู่เป็น 1 Transaction)
